# Politique de confidentialité

Dernière mise à jour : **Janvier 2024**

## 1. Responsable du traitement

**Notre Société**  
123 Rue de la Tech, 75001 Paris, France  
Email : `privacy@notresite.com`  
Délégué à la protection des données (DPO) : `dpo@notresite.com`

## 2. Données collectées

### Données que vous nous fournissez
- **Identité** : nom, prénom, email, entreprise
- **Contenu** : messages envoyés via formulaires
- **Compte** : si vous créez un compte (email, mot de passe hashé)

### Données collectées automatiquement
- **Navigation** : pages visitées, temps passé, parcours
- **Technique** : adresse IP, navigateur, OS, appareil, référent
- **Cookies** : voir section dédiée

## 3. Finalités et bases légales

| Finalité | Base légale |
|----------|-------------|
| Répondre à vos demandes (contact, newsletter) | Consentement (Art. 6.1.a RGPD) |
| Gestion des comptes clients | Contrat (Art. 6.1.b RGPD) |
| Amélioration du site (analytics) | Intérêt légitime (Art. 6.1.f RGPD) |
| Sécurité (prévention fraude, bots) | Intérêt légitime |
| Obligations légales (facturation, comptabilité) | Obligation légale |

## 4. Destinataires des données

- **Interne** : équipe support, marketing, technique
- **Sous-traitants** (sous-traitance encadrée par contrat) :
  - Hébergement : Vercel / Cloudflare
  - Analytics : Plausible (UE, sans cookies)
  - Email : Brevo (UE)
  - Base de données : Supabase (UE)
- **Autorités** : si obligation légale

## 5. Transferts hors UE

Aucun transfert hors UE sans garanties appropriées (clauses contractuelles types, décision d'adéquation).

## 5. Durées de conservation

| Données | Durée |
|---------|-------|
| Compte actif | Durée de vie du compte + 3 ans |
| Formulaires contact | 3 ans après dernier contact |
| Newsletter | Jusqu'à désinscription |
| Logs serveur / Analytics | 13 mois max (CNIL) |
| Cookies | 13 mois max |

## 6. Vos droits (RGPD)

Vous disposez des droits suivants :

| Droit | Description |
|-------|-------------|
| **Accès** | Obtenir copie de vos données |
| **Rectification** | Corriger données inexactes |
| **Effacement** | Demander suppression (droit à l'oubli) |
| **Limitation** | Geler traitement |
| **Portabilité** | Recevoir vos données en format portable |
| **Opposition** | S'opposer au traitement (marketing, profilage) |
| **Retrait consentement** | À tout moment pour traitements basés sur consentement |

**Exercice des droits** : `privacy@notresite.com` ou formulaire [ici](/contact)

Réponse sous **1 mois** (prorogeable 2 mois si complexe).

## 7. Cookies

### Catégories

| Type | Finalité | Consentement | Durée |
|------|----------|--------------|-------|
| **Strictement nécessaires** | Fonctionnement site (session, sécurité) | Non requis | Session - 1 an |
| **Analytiques** (Plausible) | Mesure audience | **Oui** | 13 mois max |
| **Marketing** | Ciblage publicitaire | **Oui** | 13 mois max |

### Gestion

- **Bandeau cookie** : choix granulaire à la première visite
- **Modification** : lien "Gérer les cookies" en bas de page
- **Refus** : possible pour analytiques/marketing (site reste fonctionnel)

### Liste des cookies

| Nom | Fournisseur | Finalité | Durée |
|-----|-------------|----------|-------|
| `plausible_session` | Plausible | Session analytics | 30 min |
| `plausible_visitor` | Plausible | Visiteur unique | 1 an |
| `session_id` | Notre site | Session utilisateur | Session |
| `csrf_token` | Notre site | Protection CSRF | Session |

## 8. Sécurité

- **Chiffrement** : TLS 1.3 (HTTPS), données au repos chiffrées (AES-256)
- **Authentification** : Mots de passe hashés (bcrypt), MFA optionnel
- **Accès** : Principe du moindre privilège, logs d'audit
- **Sauvegardes** : Quotidiennes, chiffrées, testées mensuellement
- **Tests** : Tests de pénétration annuels, bug bounty

## 9. Mineurs

Notre site ne s'adresse pas aux mineurs de moins de 16 ans. Nous ne collectons pas sciemment de données de mineurs. Si vous découvrez que nous en avons, contactez-nous pour suppression immédiate.

## 10. Modifications

Nous pouvons mettre à jour cette politique. La version à jour est toujours sur cette page. Les changements majeurs sont notifiés par email (si compte) ou bannière site.
